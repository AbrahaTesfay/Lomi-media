# Design-only HTML preview

Open `design-preview.html` in a desktop browser to view a **static design mockup** without installing Node or npm. It shares the website's stylesheet and shows the brand direction, hero, services, work and CTA.

This preview is **not** the actual interactive React website and its buttons are only visual navigation. To run the real React app, follow `README.md` (`npm install` then `npm run dev`).
