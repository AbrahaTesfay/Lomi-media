# Lomi Media Roadmap

## Delivered starter functionality
- React corporate website, eight service categories, responsive design.
- Portfolio management, original newsroom publishing, external international news links.
- Sponsor inquiry, manually verified sponsored campaign scheduling and disclosure labels.
- Server-side admin session and CSRF checks, contact/ad forms, local SQLite persistence.
- Partial English, Amharic and Tigrinya interface localization.

## Before public launch
- Complete QA, cross-device testing, accessibility checks, staff security review and HTTPS.
- Finalize verified company details, privacy notice, consent and retention process.
- Backups, monitoring, persistent data storage and domain configuration.
- Update all site translations, SEO metadata and canonical URLs.
- Review news feed usage rights and ad suitability policies.

## Later expansion
- PostgreSQL, media object storage, email delivery and staff roles.
- Approved licensed news APIs/feeds, localization CMS, approval workflows.
- Ad booking calendar, invoices, approved payment provider/webhooks, analytics with consent.
- Public case studies, searchable newsroom, video library and client portal.
